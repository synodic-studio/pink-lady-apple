# Demo Idea: "Great App Names" Skill

Captured during patchbay voice demo (2026-08-13).

## Idea

A skill (likely in pink-lady-apple) for coming up with strong Apple app names.

## What it might cover

- Naming conventions and style guidance (short, memorable, pronounceable, unique)
- Checking bundle ID availability / sanity (reverse-DNS conventions)
- Trademark sanity checks and ASC naming collision risks
- Cross-links to existing skills:
  - apple-release / testflight-ship for App Store Connect registration (bundle ID, app record name)
  - app-store-listing for metadata limits (name.txt 30 chars) and discoverability
  - sim-capture if a demo name is involved
- Possibly a brainstorm loop: propose candidates, check constraints, shortlist
